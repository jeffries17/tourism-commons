# CBT Monitoring - Staff How-To Guide

**Quick Reference Guide for ETA Staff**

---

## 🎯 What is This System?

The CBT Monitoring Dashboard helps you track your engagement with Community-Based Tourism partners. It shows at a glance which communities need attention and helps ensure regular contact.

---

## 📋 Quick Start (5 Minutes)

### 1. Access the Dashboard

- **URL**: `https://tourismcommons.org/cbt-monitoring/eswatini`
- **Login**: Use your Google account (ETA email)

### 2. Understanding the Dashboard

**Status Colors:**
- 🟢 **Green**: Community updated within last 14 days (Active)
- 🟡 **Yellow**: Updated 15-28 days ago (Needs Attention)
- 🔴 **Red**: No update in 29+ days (Inactive - Action Required!)

**Community Cards Show:**
- Last contact date
- Days since last update
- Engagement count (interactions in last 30 days)
- Content produced count
- Next planned visit (if scheduled)

---

## ✍️ Submitting an Update

### When to Submit
- After any community interaction (visit, phone call, WhatsApp, email)
- After producing content for a community
- When scheduling a future visit

### How to Submit

1. **Click "Add Update"** button (top right of dashboard)
2. **Fill out the form:**
   - **Staff Name**: Auto-filled (your name)
   - **Community**: Select from dropdown
   - **Date of Interaction**: When the interaction happened
   - **Engagement Type**: Check all that apply
     - Visit
     - Phone
     - WhatsApp
     - Email
     - No contact
   - **Update Summary**: Brief description (required, max 500 characters)
   - **Content Produced**: Check all that apply (Instagram, Facebook, Story, Video, Blog, Other)
   - **Support Needed**: Optional - note any help the community needs
   - **Next Planned Visit**: Optional - schedule future visit
3. **Click "Submit Update"**
4. **Success!** You'll see a confirmation message

### Tips for Good Updates

✅ **Do:**
- Submit updates within 24 hours of interaction
- Be specific in your summary (e.g., "Discussed festival promotion, sent Instagram post")
- Mark all content produced, even if scheduled for later
- Schedule next visit to help track follow-ups

❌ **Don't:**
- Wait weeks to submit updates
- Leave summary blank or too vague
- Forget to mark content produced

## 📊 Viewing Data

### Dashboard Features

**Search & Filter:**
- **Search bar**: Find communities by name, region, staff, or contact person
- **Region filter**: View communities by region
- **Status filter**: Show only Green/Yellow/Red communities

**Statistics Cards:**
- Total communities
- Active (Green) count and percentage
- Needs Attention (Yellow) count and percentage
- Inactive (Red) count and percentage

**View Google Sheet:**
- Click "View Sheet" button to see raw data
- Useful for detailed review or bulk edits

## 📧 Email Reminders

You'll receive automated emails:
- **Bi-weekly Reminders**: Every Monday morning
  - Lists communities that need updates (>14 days old)
  - Direct link to submit update form
- **Inactive Alerts**: For communities with no contact in 21+ days

**Action Required**: When you receive an alert, submit an update within 2 business days.

## 📄 Generating Reports (PDF)

### Option 1: Browser Print (Recommended)

1. On the dashboard, click the **"Download PDF"** button (if available)
2. Or use browser print: `Ctrl+P` (Windows) or `Cmd+P` (Mac)
3. Select "Save as PDF" as destination
4. The report includes:
   - Summary statistics
   - All communities with status colors
   - Last update dates and engagement counts

### Option 2: Export from Google Sheet

1. Click "View Sheet" button
2. Go to "Dashboard Data" tab
3. File → Download → PDF
4. Select pages and formatting options

## 🔍 Troubleshooting

### "Can't access dashboard"
- Check you're logged in with your ETA Google account
- Try clearing browser cache
- Contact IT support if issue persists

### "Form won't submit"
- Check all required fields are filled (marked with *)
- Ensure you selected at least one Engagement Type
- Try refreshing the page
- Check internet connection

### "Community not showing in dropdown"
- Community may need to be added to the system
- Contact admin to add new community
- Check Google Sheet "Communities" tab

### "Status color seems wrong"
- Status updates automatically based on last update date
- Check the "Last Update" date in the community card
- If incorrect, verify the date in Google Sheet "Responses" tab
